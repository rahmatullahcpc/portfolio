# Abuzahid Hossain — Digital Marketer Portfolio

## Files

- `index.html` — complete portfolio structure
- `css/style.css` — responsive design and styling
- `js/script.js` — navigation, animations, filtering, FAQ, counters and demo form
- `assets/images/profile.jpg` — uploaded profile photo

## Run locally

Open `index.html` in a browser.

For best development experience, use VS Code + Live Server.

## Important customization

Before publishing, replace:
1. Placeholder email and WhatsApp number
2. LinkedIn/Facebook/Instagram URLs
3. Sample project descriptions
4. Sample metrics in the results section
5. Placeholder testimonials
6. Certification details
7. Education and experience
8. Industry list if needed

Do not publish unverified results as real client outcomes.

## Contact form

The current form is front-end only. Connect it to Formspree, EmailJS, a PHP backend, Node/Express, or another form-processing service before production use.
